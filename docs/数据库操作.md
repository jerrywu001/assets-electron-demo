# 数据库操作说明

仅在本地开发或测试数据库执行以下操作。配置文件 `db.config.json` 含数据库凭据，不提交到 Git。

## 初始化

1. 复制并填写配置：

   ```powershell
   # Windows PowerShell
   Copy-Item .\db.config.example.json .\db.config.json
   ```

   ```sh
   # macOS / Linux
   cp ./db.config.example.json ./db.config.json
   ```

2. 启动应用：

   ```sh
   pnpm run dev
   ```

## 清理测试数据

```sh
pnpm run clean
```

此命令会清空资产、设备清单、采集记录、审计日志、资产分类与设备类型关联，并删除自定义资产分类和设备类型；保留部门和员工。不要对生产数据库执行。

## 注入演示数据

```sh
pnpm run seed:rich
```

脚本会补齐丰富的资产分类与设备类型及其关联，补足至少 50 名员工、30 条资产、设备清单和对应审计日志。重复执行不会重复创建已满足数量的演示资产。

需要重新生成资产演示数据时：

```sh
pnpm run clean
pnpm run seed:rich
```

## 安装后的 macOS 应用，配置数据库连接

在 `db.config.json` 填写 MySQL 地址、账号和密码。开发模式从项目根目录读取该文件；安装后的 macOS 应用从 Electron 用户数据目录读取（首次启动失败提示中会显示准确路径）。
也可以通过 `ASSET_DB_CONFIG` 指定配置文件的绝对路径。首次启动会自动创建数据库和业务表；该文件包含凭据，不会提交到 Git。

安装后的 macOS 应用可使用以下命令准备配置文件：

```sh
cd "$HOME/Library/Application Support/asset-inventory-client"

cp ./db.config.example.json db.config.json

# 编辑配置文件, 填写 MySQL 地址、账号和密码
open db.config.json

# 保存配置文件, 退出编辑器, 重启应用
```

## 安装后的 Windows 应用，配置数据库连接

- 推荐在 Windows 应用中配置数据库连接。

将 `db.config.json` 复制到 `C:\Users\<用户名>\AppData\Roaming\asset-inventory-client` 目录下。然后重启应用。

- 不推荐在 Windows 应用中指定 `ASSET_DB_CONFIG` 环境变量。只是临时的配置，重启应用后会失效。

Windows PowerShell 也可以通过 `ASSET_DB_CONFIG` 指定其他配置文件，并从同一终端启动应用：

```powershell
$env:ASSET_DB_CONFIG = "C:\path\to\db.config.json"
& "C:\Program Files\资产台账管理系统\资产台账管理系统.exe"
```
