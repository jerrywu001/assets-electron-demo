# 业务流程图

采集流程补充：先按 hostname/MAC 去重；已采集则提示并停止。数据含 MAC 和磁盘总容量，不含系统用户名；使用人在登记时填写。

> 配套：[PRD.md](./PRD.md) · [开发计划V0.1.0.md](../../develop/开发计划V0.1.0.md)
> Mermaid 源码，VS Code 装 "Markdown Preview Mermaid Support" 插件即可预览。

> 最新分类口径：PC/NB/MON 统一展示为“办公电脑”；设备清单不含“基础配置”，显示器、电源、鼠标、键盘等全部手工填写；配置采集仅回填配置信息区。

## 1. 资产全生命周期（状态机）

```mermaid
stateDiagram-v2
    [*] --> 闲置 : 登记入库\n(生成资产编号)
    闲置 --> 在用 : 分配给员工
    在用 --> 闲置 : 员工归还
    在用 --> 维修中 : 报修
    维修中 --> 在用 : 修复
    在用 --> 待回收 : 员工离职(自动)
    待回收 --> 闲置 : IT 确认回收
    闲置 --> 报废 : 报废审批(二次确认)
    在用 --> 报废 : 报废审批(二次确认)
    维修中 --> 报废 : 无法修复
    报废 --> [*] : 终态·不可回退
```

## 2. 组织架构维护流程（部门树）

```mermaid
flowchart TD
    A[组织架构页<br/>左:部门树 右:信息/员工面板] --> B{操作类型}
    B -->|新增节点| C[选父节点 → 填名称<br/>插入 departments]
    B -->|编辑| D[改名称/备注/排序]
    B -->|更换上级| E[选择新父节点<br/>禁止拖到自己子孙下]
    B -->|删除节点| F{删除保护检查}
    F -->|有子部门| G[拒绝: 请先处理子部门]
    F -->|含子孙有员工| H[拒绝: 请先调走员工]
    F -->|通过| I[删除节点 + 记审计]
    C --> J[记审计日志]
    D --> J
    E --> J
    I --> J
    J --> K[树刷新]
    E -.循环检测.-> L[新父节点不能是<br/>自身或子孙节点]
```

## 3. 资产登记流程

```mermaid
flowchart TD
    A[打开登记表单] --> B[填写基本信息<br/>分类/归属员工/状态]
    B --> C{分类确定}
    C --> D[自动生成资产编号<br/>IT-分类-年-序号]
    C --> E[带出默认设备类型]
    B --> F1[选择归属员工<br/>下拉树来自部门树<br/>仅在职员工可选]
    B --> F[填写价值信息<br/>原值/成色1-10]
    F --> G[实时计算当前净值<br/>原值×成色÷10]
    B --> H{设备清单}
    H -->|手工登记| K[添加设备类型/品牌型号/SN/规格参数<br/>手工清单行]
    B --> C1{办公电脑?}
    C1 -->|是| I[确认后 IPC 获取<br/>设备名称/MAC/CPU/内存/硬盘<br/>回填配置信息区]
    C1 -->|否| L[提交]
    I --> L
    K --> L
    L --> M{校验<br/>编号唯一? MAC 唯一?<br/>在用必有归属人?}
    M -->|不通过| B
    M -->|通过| N[主进程事务写入<br/>assets + asset_components]
    N --> O[记审计日志]
    O --> P[台账可见<br/>设备总览同步可查]
```

员工列表展示：`X资产共N设备`，X 为名下未报废资产档案数，N 为设备清单数量合计；空清单资产至少计为 1 台。

## 4. 员工离职 → 资产回收流程

```mermaid
flowchart TD
    A[IT 在员工管理页<br/>标记员工「已离职」] --> B{该员工名下<br/>有在用资产?}
    B -->|无| C[仅更新员工状态<br/>记审计]
    B -->|有| D[弹窗列出待回收资产清单]
    D --> E{IT 确认}
    E -->|取消| A
    E -->|确认| F[事务处理:<br/>员工状态=已离职<br/>+ 资产批量转「待回收」]
    F --> G[记审计日志]
    G --> H[IT 线下收回设备]
    H --> I[台账筛「待回收」<br/>逐台确认回收]
    I --> J[资产转「闲置」<br/>可重新分配]
```

## 5. 本机采集上报流程

```mermaid
flowchart TD
    A[员工/IT 点「一键采集」] --> B[主进程采集本机配置<br/>os 模块 + PowerShell CIM]
    B --> C{按 hostname+MAC<br/>匹配资产档案}
    C -->|命中| D[更新该资产的<br/>自动清单行]
    C -->|未命中| E[提示: 本机未登记<br/>请联系 IT]
    D --> F[记审计日志]
    E --> F
    F --> G[页面展示采集结果]
```

## 6. 设备总览查询流程

```mermaid
flowchart TD
    A[设备总览页] --> B[选择筛选条件<br/>设备类型/来源/关键词]
    B --> C[主进程联表查询<br/>asset_components<br/>JOIN assets/employees/departments]
    C --> D[平铺列表:<br/>每个部件一行<br/>带出所属资产与归属人]
    D --> E{点击某行}
    E --> F[跳转所属资产详情抽屉]
    F --> G{需要修改?}
    G -->|是| H[回资产登记表单编辑<br/>单一数据源入口]
    G -->|否| A
    H --> I[保存后设备总览自动反映]
```
